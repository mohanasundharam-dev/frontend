# Medical Billing Frontend + Database Starter

React Vite (JavaScript/JSX only) + Tailwind starter for medical billing, prepared for future Django DRF backend.

## Modules included
- Master
- Stock
- Product
- Purchase
- Billing
- Report
- Customer
- Setting

## Quick start
```bash
npm install
npm run dev
```
